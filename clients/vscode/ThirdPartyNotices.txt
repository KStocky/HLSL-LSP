HLSL-LSP for Visual Studio Code contains third-party software.

Microsoft DirectX Shader Compiler (DXC)
--------------------------------------

The Windows and Linux VSIX packages contain their platform's DXC runtime from
KStocky's DirectXShaderCompiler fork release 2609-kstocky.2, based on
Microsoft's DirectX Shader Compiler. cmake/Dxc.cmake pins SHA-256 checksums for
both downloads. The release packages' ReleaseNotes.md states that
LICENSE-LLVM.txt applies to all package files other than d3d12shader.h, which is
not bundled. A verbatim copy of that license is included at
licenses/dxc/LICENSE-LLVM.txt.

reproduced at licenses/npm/MICROSOFT-MIT.txt. The remaining exact package

nlohmann/json 3.12.0
--------------------

The bundled hlsl-lsp executable incorporates nlohmann/json 3.12.0 under the
MIT license. The license downloaded by CMake is reproduced at

HLSL-LSP for Visual Studio Code contains third-party software.

Microsoft DirectX Shader Compiler (DXC) 1.9.2607.13
---------------------------------------------------

The Windows VSIX contains dxcompiler.dll and dxil.dll from the official
Microsoft.Direct3D.DXC 1.9.2607.13 NuGet package acquired and checksum-verified
by cmake/Dxc.cmake. The ReleaseNotes.md included in that downloaded package
states that LICENSE-LLVM.txt applies to all package files other than
d3d12shader.h. A verbatim copy of that license is included at
licenses/dxc/LICENSE-LLVM.txt.
